# HydroSEA — Application

> **Une donnée. Un territoire. Une histoire.**

Ce dépôt contient le code applicatif d’HydroSEA.

## Périmètre prévu

- backend métier ;
- frontend web ;
- application mobile ;
- tests automatisés ;
- migrations applicatives ;
- contrats et adaptateurs d’intégration ;
- configuration locale de développement.

## Référentiel maître

Toute implémentation doit être conforme aux spécifications du dépôt `ED-INFO-SEA/hydrosea-platform`.

Une règle métier ne doit pas exister uniquement dans le code : elle doit être définie et référencée dans le dépôt de référence.

## Langue et terminologie

Les noms métier sont en français. Les noms imposés par les langages, bibliothèques, protocoles ou standards techniques peuvent rester en anglais.

## Statut

Initialisation. Le socle applicatif sera créé après stabilisation du modèle de données et des premiers contrats OpenAPI.
