# Parcours de démonstration

1. Se connecter avec l’administrateur de démonstration.
2. Créer un Tiers fictif.
3. Créer une desserte et la rendre disponible.
4. Créer, rattacher puis ouvrir le Point de consommation.
5. Créer le Contrat, ajouter le titulaire principal, valider puis activer.
6. Enregistrer le Compteur puis le poser avec son index.
7. Ouvrir la Synthèse et vérifier la frise d’activité.

Le menu « Parcours » guide ces étapes en réutilisant les écrans et API ordinaires.
