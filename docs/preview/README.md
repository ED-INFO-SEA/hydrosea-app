# HydroSEA Preview 0.1

La Preview démontre le parcours Tiers → Point de desserte → Point de consommation → Contrat actif → Compteur posé → Synthèse. Elle réutilise le monolithe modulaire, PostgreSQL, Keycloak, RabbitMQ et le contrat OpenAPI épinglé.

Lancement : `make demo`. Réinitialisation déterministe : `make demo-reset` après confirmation. Voir le [parcours](Parcours-demonstration.md), le [périmètre](Perimetre-Preview-0.1.md) et les [limites](Limites-connues.md).
